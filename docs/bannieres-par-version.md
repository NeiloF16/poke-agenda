# 38 bannières indépendantes — Poké Agenda

Chaque version dispose désormais de **son propre fichier WebP** pour les cartes de suivi, la bannière du jeu et les vitrines partagées.

Pour conserver le rendu actuel, les 38 nouvelles images contiennent initialement **la même illustration que leur groupe**. Tu peux les remplacer individuellement. Par exemple, modifier Rubis Oméga n'affectera plus Saphir Alpha.

## Modifier une bannière

1. Ouvre [assets/covers/versions sur GitHub](https://github.com/NeiloF16/poke-agenda/tree/main/assets/covers/versions).
2. Prépare une image paysage **.webp**, idéalement haute résolution (ex. 1600 × 900).
3. Donne-lui précisément le nom indiqué ci-dessous.
4. Sur GitHub, fais **Add file → Upload files**, remplace le fichier existant et valide avec **Commit changes**.
5. Vérifie que GitHub Pages termine la publication ; actualise ton navigateur avec **Ctrl + F5**.

Le cadrage est centré et peut rogner les bords selon la taille de la carte. Place les éléments importants au centre.

**Attention :** la bibliothèque reste volontairement organisée par *jeu ou duo* ; ses bannières restent dans `assets/covers/01.webp`, `02.webp`, etc. et le fond d'accueil dans `assets/covers/hero.webp`. Modifier une bannière de version ne modifie pas la bibliothèque.

Cette modification n'affecte aucune sauvegarde, aucun compte Discord et aucune donnée Supabase.
